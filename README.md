# Landlord-Tenant-Management-System

A full-stack web application designed to manage rental properties, tenants, and payments. Built for real-world scenarios, this system allows landlords to track listings, assign tenants, and monitor revenue, while tenants can view their rooms, payments, and submit complaints — all in a clean, intuitive dashboard.

Features

For Landlords:

View all property listings and occupancy status

Assign tenants to listings

Track total revenue and occupancy with charts

For Tenants:

View assigned room details and payment history

Submit maintenance complaints with urgency flags

See complaint breakdowns and payment trends in charts

Common Features:

Role-based authentication (Tenant / Landlord)

Interactive dashboards with Bar and Pie charts

Real-time updates for tenant assignments and complaints

Technologies

Frontend:

React.js with Vite

Chart.js for interactive data visualization

CSS for responsive styling

Backend:

Node.js with Express

Prisma ORM for PostgreSQL

RESTful APIs for user, listing, payment, and complaint management

Database:

PostgreSQL

Other Tools:

Git & GitHub for version control
